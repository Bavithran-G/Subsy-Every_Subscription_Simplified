# Subsy – Every Subscription, Simplified.

**Subsy** is a Subscription Management System designed to simplify and automate the complete subscription lifecycle, from product and plan creation to recurring billing, payment tracking, and revenue reporting.

## 🎯 Project Overview

The system provides a centralized platform for managing subscription-based businesses. It helps businesses handle subscriptions efficiently, automate invoice generation, track payments, and monitor recurring revenue.

## ✨ Key Features

- **User Management:** Secure registration, login, password reset, and role-based access control.
- **Product Management:** Create and manage products, product types, pricing, costs, and variants.
- **Plan Management:** Configure subscription plans with flexible billing intervals.
- **Subscription Management:** Create quotations, confirm subscriptions, manage renewals, pauses, and closures.
- **Automated Invoicing:** Generate invoices automatically from subscriptions with tax calculations.
- **Discount Management:** Configure fixed and percentage-based discounts with usage limits and validity periods.
- **Payment Tracking:** Record payments and monitor paid and outstanding invoices.
- **Customer Portal:** Allow customers to view and manage their subscriptions and invoices.
- **Revenue Dashboard:** Monitor active subscriptions, revenue, payments, and overdue invoices.

## 👥 User Roles

| Role           | Responsibilities                                 |
| -------------- | ------------------------------------------------ |
| Admin          | Full system access and configuration             |
| Internal Staff | Day-to-day subscription and billing operations   |
| Customer       | Access and manage own subscriptions and invoices |

## 🔄 Subscription Lifecycle

`Draft → Quotation → Confirmed → Active → Closed`

## 🛠️ Core Requirements

- Automated recurring invoice generation.
- Accurate tax and discount calculations.
- Prevention of duplicate or missed billing.
- Secure role-based access.
- Efficient handling of thousands of subscriptions.
- Page response time under 2 seconds.

## 🎯 Project Objective

To build a reliable and scalable subscription management platform that reduces manual work, simplifies recurring billing, and provides better visibility into business revenue.
